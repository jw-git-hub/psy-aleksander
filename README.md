# Сайт психолога Александра Красногора

Лендинг частнопрактикующего семейного психолога: рассказывает о специалисте, помогает
посетителю понять, подходит ли ему работа, и приводит его в Telegram на бесплатное
20-минутное знакомство.

**Живой сайт:** [psy-krasnogor.pro](https://psy-krasnogor.pro/)

---

## Коротко

Статический одностраничник **без сборки, фреймворков и зависимостей** — чистые
HTML, CSS и JavaScript. Ни `package.json`, ни `node_modules`: то, что лежит в
репозитории, и есть то, что раздаётся браузеру.

Это осознанное решение, а не упрощение. Сайт из одиннадцати секций живёт годами
с редкими правками контента; бандлер здесь добавил бы шаг между исходником и
продакшеном, но ничего не дал бы взамен. Зато нет цепочки транзитивных
зависимостей, нечему протухать и нечего пересобирать через два года, чтобы
поменять цену в прайсе.

| | |
|---|---|
| **Стек** | HTML5, CSS3, JavaScript (ES6+, vanilla) |
| **Хостинг** | GitHub Pages + собственный домен (`CNAME`) |
| **CSS** | mobile-first, БЭМ, кастомные свойства, Grid и Flexbox |
| **Аналитика** | Яндекс.Метрика — цели, вебвизор, делегированный трекинг |
| **SEO** | Schema.org JSON-LD (`@graph`), Open Graph, hreflang, sitemap, robots |
| **GEO** | `llms.txt`, блок-выжимка фактов, FAQ с прямыми ответами |
| **Тесты** | собственная оснастка: Bash + четыре валидатора на Node |
| **Вес** | ~90 КБ HTML, 84 КБ CSS, 36 КБ JS, шрифты 235 КБ — всё локально |

## Что умеет

- **Квиз подбора формата** — три шага, результат-рекомендация и кнопка
  «скопировать» — собирает ответы в готовое сообщение для Telegram, чтобы
  человеку не пришлось объяснять свой запрос с нуля.
- **Галерея дипломов** с лайтбоксом: превью → полноразмерный скан,
  перелистывание стрелками, клавиатурой и свайпом, фокус-trap на время показа.
- **Мобильное меню** с бэкдропом, блокировкой скролла и `inert` на скрытой
  навигации, чтобы `Tab` не проваливался в невидимые ссылки.
- **FAQ и «Мой подход»** на нативных `<details name>` — один открытый пункт за
  раз силами платформы, с JS-фолбэком для Safari младше 17.
- **Scroll-анимации** и подсветка активного пункта навигации через
  `IntersectionObserver`.
- **Sticky-CTA** на мобильных: кнопка записи в шапке, уступающая место нижней
  панели, когда та появляется.
- Страница политики конфиденциальности с собственными стилями и `noindex`.

## Архитектура

```
index.html          одностраничник, 11 секций
pages/privacy.html  политика конфиденциальности

css/
  fonts.css         @font-face локальных Inter и Manrope
  variables.css     единственный источник цветов, отступов, типографики
  reset.css
  base.css          типографика, контейнер, утилиты
  style.css         секции и компоненты
  legal.css         правовые страницы

js/
  main.js           меню, smooth scroll, шапка, анимации, лайтбокс, трекинг
  quiz.js           квиз подбора формата
  metrika.js        инициализация Яндекс.Метрики

tools/              оснастка проверок
docs/               спеки, планы и отчёты по итерациям
fonts/ img/         локальные шрифты и WebP-изображения
```

**Принципы, которых держится код:**

- Разделение слоёв: HTML — структура, CSS — вид, JS — поведение. Инлайн-стилей
  и инлайн-скриптов нет нигде, кроме одной строки в `<head>`, которая ставит
  класс `js` на `<html>` — от неё зависит корректная деградация без JavaScript.
- Никаких магических значений в CSS: цвета, отступы, тени, скорости переходов
  живут в `variables.css`.
- Один модуль — одна ответственность, каждый блок в `main.js` изолирован и
  начинается с комментария о том, что он делает и почему.
- Трекинг делегированный: один слушатель на `document` обслуживает все
  16 элементов с атрибутом `data-analytics` — новая кнопка не требует
  ни строчки JS.

**Доступность и производительность:**

- `aria-expanded`, `aria-current`, управление `inert`, видимый фокус, разметка
  landmark-ролями, контрастность по WCAG AA.
- `prefers-reduced-motion` отключает анимации явно — каждой из них прописан
  `animation: none` в reduce-блоке.
- Шрифты скачаны локально и разбиты по подмножествам (latin / cyrillic / ext),
  критичные — в `preload`; зависимость от Google Fonts убрана целиком.
- Изображения в WebP с JPG-фолбэком через `<picture>`, hero-фото раздаётся
  адаптивно через `srcset` и предзагружается с `fetchpriority="high"`.
- Скрипты в `<head>` с `defer`.

## SEO и оптимизация под ИИ-выдачу

Помимо классического SEO сайт готовился к тому, что ответ пользователю всё чаще
собирает не поисковая выдача, а языковая модель.

**Schema.org.** Разметка — единый `@graph` из 13 связанных через `@id` узлов:
специалист, практика, услуги, пять офферов в двух валютах, квалификации, место,
FAQ. Валидатор schema.org: ноль ошибок, ноль предупреждений.

**Под ИИ-системы:** блок-выжимка ключевых фактов под первым экраном в форме,
удобной для цитирования; FAQ, где каждый ответ начинается с прямого ответа, а не
с подводки; `llms.txt` с фактурой в машиночитаемом виде; явные разрешения
ИИ-краулерам в `robots.txt`.

**Отдельное требование — приватность.** Точный адрес очного приёма не публикуется
нигде: ни в тексте, ни в разметке, ни в `llms.txt` — только уровень острова.
Ни `streetAddress`, ни координат, ни `GeoCoordinates`. Требование безопасности
приоритетнее полноты схемы и локального SEO, поэтому оно закреплено
автоматическими проверками, а не памятью разработчика.

## Проверки

Тестового фреймворка в проекте нет и он не нужен — вместо него собственная
оснастка, проверяющая то, что в статическом сайте реально ломается: фактуру,
разметку и согласованность текста между HTML и JSON-LD.

```bash
bash tools/check-content.sh
```

Один запуск прогоняет 15 разделов проверок:

- целостность документа, наличие всех десяти якорей навигации;
- **отсутствие** адреса и координат — проверка на то, чего быть не должно;
- актуальность фактуры: цены, длительность сессий, часы приёма в двух поясах;
- запрещённые конструкции схемы, которые уже однажды приводили к ошибкам;
- посимвольное совпадение видимого FAQ с разметкой `FAQPage`
  (`check-faq-sync.mjs` нормализует `&nbsp;` перед сравнением);
- совпадение цен в прайсе с офферами в JSON-LD (`check-offers.mjs`);
- содержимое `js/` — квиз тоже говорит с пользователем о форматах и ценах;
- валидность всех блоков JSON-LD (`check-jsonld.mjs`).

Валидаторам нужен только Node — без установки пакетов.

## Разработка

Сборки нет, поэтому достаточно отдать папку любому статическому серверу:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Деплой — пуш в `main`: GitHub Pages подхватывает изменения автоматически.
Служебные файлы (`docs/`, `tools/`, `JOURNAL.md`) остаются в репозитории, но
исключены из публикации через `_config.yml`.

[`JOURNAL.md`](JOURNAL.md) — журнал разработки: принятые решения и грабли, на
которые легко наступить повторно. В нём же зафиксировано, почему код местами
выглядит именно так.
