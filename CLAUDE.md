# Сайт психолога — Рабочий файл проекта

## Описание проекта
Разработка сайта для психолога. Статический сайт (HTML/CSS/JS) с чистой архитектурой и разделением ответственности.

---

## Роли моделей

| Модель | Роль | Задачи |
|--------|------|--------|
| **Opus** | Архитектор и ревьюер | Планирование, проектирование структуры, проверка кода на ошибки, финальный ревью |
| **Sonnet** | Разработчик | Написание HTML, CSS, JS кода по плану от Opus |

### Порядок работы
1. **Opus** продумывает план и архитектуру задачи
2. **Sonnet** пишет код по плану
3. **Opus** проверяет результат на ошибки и качество

---

## Правила чистой разработки

### Запрещено
- **Inline-стили** — никаких `style="..."` в HTML
- **Inline-скрипты** — никаких `<script>код</script>` в HTML (только подключение внешних файлов)
- **Inline-обработчики** — никаких `onclick="..."`, `onload="..."` в HTML
- **CSS в JavaScript** — стили задаются только через CSS-классы
- **Магические числа** — все значения выносить в CSS-переменные

### Обязательно
- Все стили — в файлах `css/*.css`
- Все скрипты — в файлах `js/*.js`
- Семантическая HTML-разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- БЭМ-подход для именования CSS-классов (блок__элемент--модификатор)
- CSS-переменные для цветов, шрифтов, отступов в `:root`
- Комментарии к каждому разделу кода
- Адаптивность (mobile-first подход)
- Оптимизация изображений (WebP, lazy loading)

### Именование файлов
- Только латиница, строчные буквы, дефис: `about-page.html`, `hero-section.css`
- CSS: один файл на компонент/секцию при необходимости
- JS: один файл на модуль функциональности

## Структура проекта

```
Сайт Санька/
├── CLAUDE.md           ← этот файл (рабочая документация)
├── JOURNAL.md          ← журнал разработки (компактный)
├── index.html          ← главная страница
├── css/
│   ├── variables.css   ← CSS-переменные (цвета, шрифты, размеры)
│   ├── reset.css       ← сброс стилей браузера
│   ├── base.css        ← базовые стили (типографика, body)
│   └── style.css       ← основные стили компонентов
├── js/
│   └── main.js         ← основной скрипт
├── img/                ← изображения (WebP предпочтительно)
├── fonts/              ← локальные шрифты
├── pages/              ← дополнительные HTML-страницы
├── components/         ← переиспользуемые HTML-компоненты
└── assets/             ← прочие ресурсы (иконки, документы)
```
